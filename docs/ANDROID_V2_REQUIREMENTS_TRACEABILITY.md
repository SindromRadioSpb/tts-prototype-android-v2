| REQ-004 | No cloud app storage dependency. | Local-first ownership. | [Architecture](ANDROID_V2_ARCHITECTURE.md), [Data Model](ANDROID_V2_DATA_MODEL.md) | Room, app storage, export | Repository/export tests | Designed | Cloud provider APIs may be used only for translation/TTS, not app storage. |

| REQ-007 | Local library persists on device. | Premium data ownership. | [Data Model](ANDROID_V2_DATA_MODEL.md), [Local Library Plan](ANDROID_V2_LOCAL_LIBRARY_PLAN.md) | Room database, repository, Library UI | `RoomLibraryRepositoryTest`; `ClassicModeViewModelTest`; `LibraryViewModelTest`; `AppDatabaseMigrationTest` | Partial | M7 adds Room-backed browse/open/archive/restore/delete; P014 adds Classic-owned Library v3 modal and schema v2 text metadata. Manual UI evidence remains pending. |
| REQ-008 | Library export includes audio-aware metadata. | No silent audio loss. | [Export Spec](ANDROID_V2_LIBRARY_EXPORT_SPEC.md), ADR-0005 | Export layer, audio repository | `AudioStorageRepositoryTest`; `LibraryZipExportRepositoryTest` | Partial | M6 exports audio-aware metadata and files; P014 adds `source_label` and `topic` to exported text metadata. SAF/share UI wiring remains future work. |
| REQ-009 | API keys are not exported or logged. | Security and privacy. | [Settings and Secrets](ANDROID_V2_SETTINGS_AND_SECRETS.md) | `core.settings`, `data.settings`, `feature.settings`, exports, provider adapters | `ProviderSettingsRepositoryTest`; `SettingsViewModelTest`; provider adapter tests; secret scan; `LibraryZipExportRepositoryTest` | Partial | Credentials are read from secure settings and never committed/exported; service-account JSON is accepted only through SAF attachment and masked status. Device evidence and real endpoint smoke remain pending. |
| REQ-010 | Hebrew RTL is readable. | Core learning UX. | [Classic UI](ANDROID_V2_CLASSIC_MODE_UI_SPEC.md) | Compose text layout | UI evidence and accessibility smoke | Partial | M2 keeps right-aligned source and row Hebrew text; manual evidence is still pending. |
| REQ-011 | Long content scrolls. | Mobile usability. | [Classic UI](ANDROID_V2_CLASSIC_MODE_UI_SPEC.md), [UI Evidence](ANDROID_V2_UI_DOD_EVIDENCE.md) | Compose layout | Compose UI/manual tests | Partial | M0 shell uses scrolling; formal evidence pending. |
| REQ-012 | Export does not fail because one audio file is missing. | Ownership and backup reliability. | [Export Spec](ANDROID_V2_LIBRARY_EXPORT_SPEC.md), [Audio Architecture](ANDROID_V2_AUDIO_ARCHITECTURE.md) | Export snapshot writer | `LibraryZipExportRepositoryTest` | Partial | M6 repository export writes partial backup and missing-audio manifest; UI evidence remains pending. |
| REQ-013 | Provider failures are visible. | No hidden provider switching. | [Error Handling](ANDROID_V2_ERROR_HANDLING.md), [Provider Plan](ANDROID_V2_PROVIDER_IMPLEMENTATION_PLAN.md) | ViewModel state, provider adapters | `TranslationProvidersTest`; `TtsProvidersTest`; `ClassicModeViewModelTest` | Partial | Missing credentials and mapped provider failures are visible for translation and source-level TTS; manual UI evidence remains pending. |
| REQ-014 | No silent fallback for quota, billing, invalid-key. | Prevent misleading output and cost surprises. | [Provider Policy](ANDROID_V2_PROVIDER_POLICY.md), [Error Handling](ANDROID_V2_ERROR_HANDLING.md) | Provider adapters | `TranslationProvidersTest`; `TtsProvidersTest`; `ClassicModeViewModelTest`; future real-key smoke | Partial | Keyed adapters do not fallback on missing credentials or HTTP failures; real quota/billing/invalid-key smoke remains manual. |
| REQ-015 | Documentation updates are mandatory. | Living control plane. | [Maintenance Policy](DOCUMENTATION_MAINTENANCE_POLICY.md), ADR-0006 | Patch process | `git diff --check`, patch register review | Active | Applies immediately. |
| REQ-016 | Fake generation must not be mistaken for provider output. | M2 shipped before provider registry. | [Classic UI](ANDROID_V2_CLASSIC_MODE_UI_SPEC.md), [Provider Plan](ANDROID_V2_PROVIDER_IMPLEMENTATION_PLAN.md) | `feature.classic`, `ui`, `data.provider.translation` | `ClassicModeViewModelTest`; `TranslationProvidersTest` | Partial | M3 replaces M2 fake shell with provider provenance; fake providers are test-only unless explicitly injected. |
| REQ-017 | Audio files must be owned locally before metadata is saved. | Export reliability and privacy. | [Audio Architecture](ANDROID_V2_AUDIO_ARCHITECTURE.md), [Data Model](ANDROID_V2_DATA_MODEL.md) | `data.audio`, Room `audio_assets`, `row_audio` | `AudioStorageRepositoryTest` | Partial | M5 adopts row audio into app files and records metadata; text-level audio remains planned. |
| REQ-018 | Missing audio must not make readable rows unusable. | Premium data safety. | [Audio Architecture](ANDROID_V2_AUDIO_ARCHITECTURE.md), [Error Handling](ANDROID_V2_ERROR_HANDLING.md) | `data.audio`, playback layer | `AudioStorageRepositoryTest` | Partial | M5 marks missing asset metadata and returns missing result; UI display remains future work. |
| REQ-019 | Saved library rows can be edited, reset, reordered, deleted, and extended without breaking row order or edit metadata. | Classic Mode requires a durable local library, not a static generated table. | [Local Library Plan](ANDROID_V2_LOCAL_LIBRARY_PLAN.md), [Classic UI](ANDROID_V2_CLASSIC_MODE_UI_SPEC.md) | `feature.library`, `data.repository`, `ui` | `RoomLibraryRepositoryTest`; `LibraryViewModelTest` | Partial | M8 adds ViewModel/UI row mutation workflow and unit coverage; manual Compose/device evidence remains pending. |
| REQ-020 | Classic Mode Library v3 mobile UI must match the v4 screenshot workflow while fixing Android clipping/overflow. | Manual smoke found current draft UI does not match source mobile web experience. | [Classic Mobile v4 UI](ui/ANDROID_V2_CLASSIC_MODE_MOBILE_V4_UI_SPEC.md), [Classic UI](ANDROID_V2_CLASSIC_MODE_UI_SPEC.md) | `feature.classic`, `feature.library`, `ui` | `ClassicModeViewModelTest`; `LibraryViewModelTest`; future Compose UI tests, screenshot/manual evidence | Partial | P014 implements Classic-owned Library v3 modal, filters, dropdowns, chips, cards, stacked actions, and metadata editor. Manual screenshot/IME evidence and Compose UI tests remain pending. |
| REQ-021 | Provider credentials must use the correct provider-specific UX: JSON attachment for service-account providers and API-key paste for Gemini legacy. | Source parity and safer credential handling. | [Settings and Secrets](ANDROID_V2_SETTINGS_AND_SECRETS.md), [Classic Mobile v4 UI](ui/ANDROID_V2_CLASSIC_MODE_MOBILE_V4_UI_SPEC.md), [Provider Policy](ANDROID_V2_PROVIDER_POLICY.md) | `feature.settings`, SAF file picker, settings repository, provider adapters | `ProviderSettingsRepositoryTest`; `SettingsViewModelTest`; `TranslationProvidersTest`; `TtsProvidersTest`; future instrumented SAF smoke | Partial | P019 keeps JSON attachment for GCP/Google TTS, changes Gemini primary UX to pasted API key, and retains the JSON wrapper only for compatibility. Manual SAF/emulator and real-key evidence remain pending. |
| REQ-022 | Classic row actions must support real row TTS playback, row audio cache state, and saved row notes. | Source prototype action column contains TTS play, cache marker, and notes; Android must preserve behavior without clipped web table controls. | [Classic UI](ANDROID_V2_CLASSIC_MODE_UI_SPEC.md), [Classic Mobile v4 UI](ui/ANDROID_V2_CLASSIC_MODE_MOBILE_V4_UI_SPEC.md), [Audio Architecture](ANDROID_V2_AUDIO_ARCHITECTURE.md) | `feature.classic`, `data.audio`, `data.repository`, Room `sentence_notes`, `ui` | `ClassicModeViewModelTest`; `RoomLibraryRepositoryTest`; `AppDatabaseMigrationTest`; future device playback smoke | Partial | P017 adds row play with selected TTS provider, row cache adoption for saved rows, and `sentence_notes` persistence. Manual real-key playback and export of notes remain pending. |
| REQ-022 | Android v2 must import source-prototype `linguist-pro-library` JSON exports without losing Library v3 card metadata. | Existing user migration from `E:\projects\tts-prototype-android` exports. | [Export Spec](ANDROID_V2_LIBRARY_EXPORT_SPEC.md), [Local Library Plan](ANDROID_V2_LOCAL_LIBRARY_PLAN.md), [Classic Mobile v4 UI](ui/ANDROID_V2_CLASSIC_MODE_MOBILE_V4_UI_SPEC.md) | `data.repository`, `feature.library`, `ui` | `RoomLibraryRepositoryTest`; future device SAF import smoke with real exported file | Partial | P016 imports old web JSON texts/sentences, preserves `text_key`, card metadata, dates, archive flag, and marks legacy audio links as missing placeholders. Android ZIP import and real-audio bundle migration remain future work. |
| REQ-023 | Generated Classic results must render as the source-style table with explicit column controls, adjustable widths, and auto-next row playback. | Source prototype `🧩 Таблица: отображение и сценарии` block and Android screenshot gap `Результат_андроид.png`. | [Classic UI](ANDROID_V2_CLASSIC_MODE_UI_SPEC.md), [Classic Mobile v4 UI](ui/ANDROID_V2_CLASSIC_MODE_MOBILE_V4_UI_SPEC.md) | `feature.classic`, `ui.AppRoot`, `data.audio` | `ClassicModeViewModelTest`; future Compose UI/device playback smoke | Partial | P018 replaces row cards with table columns `▶✎`, `Иврит`, `Огласовки`, `Транслит`, `Перевод`, adds `Колонки` controls, clamps resize widths, and starts auto-next playback from the selected row. Manual screenshot/audio evidence remains pending. |
| REQ-024 | Provider-generated table rows and row audio cache must reflect current provider/profile settings. | User smoke found Google Free 429s, Gemini one-string rows, stale TTS cache, translit profile no-op after import, provider changes not rebuilding rows, and Gemini HTTP 400 misclassification. | [Classic UI](ANDROID_V2_CLASSIC_MODE_UI_SPEC.md), [Provider Plan](ANDROID_V2_PROVIDER_IMPLEMENTATION_PLAN.md), [Settings and Secrets](ANDROID_V2_SETTINGS_AND_SECRETS.md) | `data.provider.translation`, `feature.classic`, `ui.AppRoot`, `data.audio` | `TranslationProvidersTest`; `ClassicModeViewModelTest`; future real-key/audio smoke | Partial | P019 implements prototype-compatible Google Free batch requests, Gemini strict JSON table prompt, TTS cache-key validation, last-column resize, collapsible panels, and translit fallback. P020 rebuilds rows on translation-provider changes, hides unsupported System fallback TTS controls, and adds prototype transliteration fixtures. P021 restores source-compatible `gemini-flash-latest`, JSON response mode, and Gemini HTTP 400 body-aware mapping. Manual endpoint/audio evidence remains pending. |
| REQ-025 | Generated table cell text must remain selectable on touch devices and desktop emulators. | Learners need to copy Hebrew, niqqud, transliteration, and translation from table cells. | [Classic UI](ANDROID_V2_CLASSIC_MODE_UI_SPEC.md), [Classic Mobile v4 UI](ui/ANDROID_V2_CLASSIC_MODE_MOBILE_V4_UI_SPEC.md) | `ui.AppRoot` | future Compose UI/manual emulator evidence | Partial | P020 wraps non-action table cell text in selectable containers. Manual touch/mouse selection evidence remains pending. |
