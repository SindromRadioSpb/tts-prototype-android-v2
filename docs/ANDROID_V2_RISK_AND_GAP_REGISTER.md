# Android v2 Risk and Gap Register

Date: 2026-04-25

| ID | Area | Risk / gap | Severity | Likelihood | Impact | Mitigation | Owner / next action | Status | Updated date |
|----|------|------------|----------|------------|--------|------------|---------------------|--------|--------------|
| RISK-001 | Security | GCP credential strategy now supports service-account JSON on device, but real endpoint/device smoke is not yet collected. | High | Medium | JSON parsing or OAuth may work in tests but fail against a real project. | P015 uses SAF, encrypted storage, masked status, OAuth JWT bearer auth, and no silent fallback. | Run manual smoke with attached service-account JSON and document result. | Partially mitigated | 2026-04-25 |
| RISK-002 | Security | Gemini key strategy now supports JSON wrapper, but cost-warning UX and real endpoint smoke are not yet collected. | High | Medium | Secret leakage or unexpected cost/confusion. | Encrypted storage, masked status, no export/logging; JSON wrapper validation; keyed adapter maps failures visibly without fallback. | Add cost-warning UX before release and run manual smoke. | Partially mitigated | 2026-04-25 |
| RISK-003 | Language | niqqud strategy is unresolved on Android without sidecars. | Medium | High | Rows may lack niqqud or show inconsistent quality. | Treat niqqud as optional/degraded; document provider before implementation. | Decide in M3. | Open | 2026-04-25 |
| RISK-004 | Language | Transliteration parity with source JS may drift. | Medium | Medium | Learners see inconsistent transliteration. | Capture fixtures from source behavior and test Kotlin implementation. | Add fixtures in M3/M13. | Open | 2026-04-25 |
| RISK-005 | Export | Audio export reliability may fail under missing files or SAF interruption. | High | Medium | User loses backup confidence. | Snapshot export, missing-audio manifest, partial backup flag. | M6 repository export implemented; SAF interruption still needs UI/device validation. | Mitigated in repository; open for UI | 2026-04-25 |
| RISK-006 | Import | Old web JSON import compatibility is not yet specified at field level. | Medium | Medium | Existing users cannot migrate data. | Build compatibility mapping and fixture tests. | Implement in M11. | Open | 2026-04-25 |
| RISK-007 | Android storage | SAF and scoped storage restrictions can break export paths. | High | Medium | Export cannot write where user expects. | Use SAF/create document and share sheet; avoid raw external paths. | Repository ZIP writer exists; SAF UI validation moves to M7/M12. | Open | 2026-04-25 |
| RISK-008 | Provider UX | Quota/billing errors may be mistaken for transient failures. | High | Medium | Users retry uselessly or incur confusion. | Dedicated error categories, keyed adapter HTTP mapping, and no silent fallback. | Validate real quota/billing/invalid-key responses with restricted test keys before release. | Active | 2026-04-25 |
| RISK-009 | Product | IDE Mode scope creep can delay Classic Mode. | Medium | High | Production workflow slows down. | Keep IDE experimental and separate. | Review at M10 only. | Open | 2026-04-25 |
| RISK-010 | Process | Documentation can become stale after code patches. | High | Medium | Future agents implement against wrong contracts. | Maintenance policy, patch register, ADR rule. | Enforce every patch. | Active | 2026-04-25 |
| RISK-011 | Security | Secret leakage in logs, exports, screenshots, or Git. | High | Medium | User credentials exposed. | Secret scan, encrypted settings, export exclusion, masked UI status only. | Keep enforcing every patch; add manual screenshot review before release. | Active | 2026-04-25 |
| RISK-012 | Testing | Robolectric does not currently run unit tests at app target SDK 36. | Low | Medium | Local Room tests fail if default Robolectric SDK follows target SDK. | Pin repository tests to SDK 35 until Robolectric supports SDK 36 in this project. | Revisit during dependency updates. | Mitigated | 2026-04-25 |
| RISK-013 | Product | Test fake translation output could be exposed as production output. | High | Low | User may trust non-production language output. | Runtime registry uses `google_translate_free` plus missing-configuration providers; fake providers are injected only in tests. | Keep fake providers out of production registry unless explicitly gated. | Mitigated | 2026-04-25 |
| RISK-014 | Provider | `google_translate_free` uses an unofficial best-effort endpoint that can change without notice. | Medium | High | Translation may fail or parse incorrectly. | Map invalid responses visibly; keep GCP/Gemini as future configured alternatives; add manual smoke evidence before release. | Reassess in M13 and before release. | Active | 2026-04-25 |
| RISK-015 | Audio | Android platform TTS availability and Hebrew voice quality vary by device. | Medium | High | Fallback audio may be unavailable or poor quality. | Label as low quality, map unsupported language, require emulator/device smoke before release. | Validate in M5/M13 manual QA. | Active | 2026-04-25 |
| RISK-016 | Security | Google Online TTS service-account JSON is stored on device and may be sensitive if the device is compromised. | High | Medium | Credential extraction from a rooted/compromised device or backup misconfiguration. | P015 stores JSON only through encrypted app-private settings, never APK/resources/Room/export/logs, and discards external file path. | Run manual smoke and reassess whether brokered auth is required before release. | Partially mitigated | 2026-04-25 |
| RISK-017 | Audio | `MediaPlayer` playback is not yet manually verified on device/emulator. | Medium | Medium | Audio controls may fail despite unit-level storage checks. | Keep UI playback controls disabled until M7/M12 evidence; add manual smoke before release. | Validate during M7/M12/M13. | Open | 2026-04-25 |
| RISK-018 | UI | Library lifecycle UI is covered by ViewModel tests but not by Compose screenshot/manual device evidence. | Medium | Medium | Layout or touch issues may survive unit validation. | P014 moves Library into Classic-owned v4 modal and stacks destructive actions. | Capture UI evidence after navigation polish. | Partially mitigated; evidence pending | 2026-04-25 |
| RISK-019 | UI/Data | Row editing controls are covered by ViewModel tests but not by Compose/manual keyboard evidence, and P014 prioritizes text metadata UI over row mutation UI in the v4 modal. | Medium | Medium | Row-level edit access may be unclear after moving away from the separate Library tab. | Keep repository/ViewModel tests; reconcile final row-edit access path during M12/M13 without breaking v4 Library card parity. | Add UI path/evidence for row-level edit/reset/reorder or document its final screen. | Active | 2026-04-25 |
| RISK-020 | Android security | Android Keystore encrypted storage is unit-tested through abstractions but not device-smoke-tested. | High | Medium | Credentials may fail to persist/decrypt on real devices or after backup/restore. | Add emulator/device smoke for save/restart/delete; keep real providers disabled until evidence exists. | Validate during M12/M13 or before enabling keyed providers. | Open | 2026-04-25 |
| RISK-021 | Product/Audio | Classic `Speak` currently validates synthesis and cache output but does not adopt generated audio into library metadata or play it audibly. | Medium | Medium | User may expect full playback lifecycle during smoke. | Show completion file name or mapped error; keep row/text audio adoption under M5/M7 flows until explicitly wired. | Wire playback/adoption in next audio UI patch if manual smoke requires audible output. | Active | 2026-04-25 |
| RISK-022 | UI | Pixel parity with v4 screenshots may conflict with native Android adaptation. | Medium | High | Blind cloning can preserve web clipping or poor touch behavior. | P014 implements visual/behavioral parity while using native stacked cards, scrollable modal content, and touch-safe controls. | Capture screenshot evidence and adjust spacing without reintroducing clipping. | Partially mitigated; evidence pending | 2026-04-25 |
| RISK-023 | UI | Dropdown menus may cover too much content or push layout on small screens. | Medium | Medium | Filters become unusable on compact phones. | P014 uses bounded dropdown menus with checkmarks and vertical filter layout. | Capture expanded dropdown evidence on narrow emulator. | Partially mitigated; evidence pending | 2026-04-25 |
| RISK-024 | UI | Library card actions can clip/overflow like the source web screenshot. | High | High | Critical actions become unreachable. | P014 stacks all card actions full-width on narrow layout; no horizontal scrolling is required for actions. | Verify `Открыть/Продолжить/Изменить/В архив/Удалить` on narrow emulator. | Partially mitigated; evidence pending | 2026-04-25 |
| RISK-025 | Security/UI | JSON credential file attachment can leak file paths or secrets if treated as plain UI state. | High | Medium | Credential exposure in logs/screenshots/export. | P015 uses SAF, parses/validates, stores credentials encrypted, discards path, masks status, and covers parser/provider paths with unit tests. | Collect emulator evidence and run secret scan before commit. | Partially mitigated; evidence pending | 2026-04-25 |
| RISK-026 | UI | Metadata dialog keyboard can hide Save/Cancel or corrupt mixed Hebrew/Latin input. | Medium | Medium | Users cannot complete metadata edits. | P014 uses a scrollable metadata dialog with explicit Save/Cancel; IME evidence is still required. | Capture keyboard-open evidence. | Partially mitigated; evidence pending | 2026-04-25 |
| RISK-027 | Language/UI | Hebrew RTL rendering in Library titles/cards may break when mixed with Russian/Latin. | Medium | Medium | Saved text titles become hard to read. | P014 keeps Hebrew text visible in titles/source input and uses wrapped card content; mixed-direction manual evidence remains required. | Add Compose/manual RTL evidence. | Partially mitigated; evidence pending | 2026-04-25 |
| RISK-028 | Data/UI | Library v3 metadata parity requires `source_label` and `topic` fields that existing v1 installs do not have. | Medium | Medium | Metadata editor/export could fail or lose source/theme values after upgrade. | P014 adds Room schema version 2 and `MIGRATION_1_2`, plus repository/export tests for the new nullable fields. | Verify migration on an installed debug build with existing v1 data. | Partially mitigated; device upgrade pending | 2026-04-25 |
